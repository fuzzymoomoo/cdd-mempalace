# Upstream Example Drafts

This folder stores public-safe example drafts that are suitable for contribution
back to the MemPalace ecosystem.

Internal planning notes, PR bodies, workflow checklists, and issue/comment
drafts now live back in the main `cdd` workspace so the public bridge repo stays
focused on reusable example material.

## Current Drafts

- [software-engineering-memory-example.md](software-engineering-memory-example.md)
  Upstream-friendly example showing how MemPalace can support software
  engineering memory and durable project artifacts.
- [software-engineering-handoffs-example.md](software-engineering-handoffs-example.md)
  Upstream-friendly example for agent-to-agent or human-to-agent software
  handoffs over shared memory.
- [personal-operating-system-memory-example.md](personal-operating-system-memory-example.md)
  Upstream-friendly example for using MemPalace as a continuity layer in a
  local-first personal operating system or executive-function support tool.
- [customer-facing-bot-memory-example.md](customer-facing-bot-memory-example.md)
  Upstream-friendly example for using MemPalace as a continuity layer in a
  customer-facing bot such as sales, support, service, or onboarding.
